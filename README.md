# AI-Gesture-Space-Universe
AI Gesture Space Universe - An interactive AI project that turns your hand gestures into a living galaxy of particles using Python, OpenCV &amp; MediaPipe.
Control a whole universe with just your hand!

This project uses Python, OpenCV and MediaPipe Hand Tracking to track your hand in real-time and turn your gestures into beautiful particle effects.

No mouse. No keyboard. Just your hand and AI.

## Features
- Real-time hand tracking
- Particle universe that follows your gestures
- Pinch to zoom, move to explore
- Smooth and magical visual effects

## How to Run
1. Install requirements:
   pip install opencv-python mediapipe

2. Run the project:
   python universe.py

3. Show your hand to the camera and enjoy!

## Built With
- Python
- OpenCV
